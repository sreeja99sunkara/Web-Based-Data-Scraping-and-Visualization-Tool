# Web-Based-Data-Scraping-and-Visualization-Tool
Developed a single-page web interface using Python and React.js to automate web data scraping, store structured data in databases, and build RESTful APIs for front-end integration. 
Automated data collection from the web and structured it using Python.
Developed RESTful API endpoints using Flask for front-end integration.
Built interactive dashboards in React.js to search, filter, and analyze data visually.
Streamlined data workflows using Pandas and Excel-based processing.

A Flask backend for data scraping and API services
Two React frontends (standard UI and Kendo UI)
